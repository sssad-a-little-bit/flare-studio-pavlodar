## Дополнительная проверка по исходникам

- У каждого поля есть связанный label; ошибки связаны через aria-describedby и aria-invalid.
- Результат копирования объявляется через aria-live. При отказе Clipboard API текст выделяется для ручного копирования; успех в этом случае не имитируется.
- Анимации Batyr 200–280 мс; Picasso 200–300 мс. Для prefers-reduced-motion анимации/переходы отключены, smooth scrolling отключён. Предпочтение ОС в браузере отдельно не переключалось.
- Мобильные панели закреплены; у нижней части страницы есть запас, учитывается safe-area-inset-bottom.
- В форме Picasso нет ФИО ребёнка или даты рождения. Возраст вводится свободным текстом.
- Нет fetch, отправки формы, аналитики, localStorage или серверного хранения обращений. Форма работает только в памяти страницы.
- Нет расчёта цены, доступных слотов, отзывов, опыта, гарантий, выдуманных программ или расписания.
- Галереи реальных работ и сравнения «до/после» не показываются: разрешённых материалов не предоставлено. Поэтому тест модального просмотра/закрытия Esc неприменим.
- Внешние URL сверены с конфигом и источниками. Реальный звонок не совершался. Сообщения не отправлялись. Instagram и ссылки внутри профиля недоступны для проверки; их внешняя доступность не подтверждена.

## Среда и ограничение dev

Пустой проект: AGENTS.md и существующий стек не обнаружены. Созданы React + TypeScript + Vite. Сборка выполняется командой npm run build, предпросмотр — npm run preview -- --port 5173.

В текущей ограниченной Windows-среде стандартный запуск Vite dev столкнулся с Access is denied при поиске esbuild по родительским каталогам. configLoader native устраняет эту проблему для чтения конфигурации, production build и preview работают. Проверка интерфейса выполнена на production preview. Ограничение dev не скрыто: для воспроизводимого локального просмотра используйте проверенные команды из README.

## Правки по комментариям браузера

- Полностью переработана геометрия автомобильной иллюстрации: единый ракурс спереди и сбоку, колёса под боковыми арками, фары и решётка на передней плоскости; тень соответствует положению автомобиля.
- Заголовок «Поверхность меняет впечатление.» и надпись раздела выровнены по центру всей секции на мобильном и большом экране. Блок процесса сохранён.
- Абстрактная композиция заменена узнаваемым капотом автомобиля с прозрачной защитной плёнкой, поднятым краем и кобальтовым ракелем. Подпись «Иллюстрация» перенесена в свободную светлую область.
- Повторно проверены ширины 360, 508 и 1440 px, центрирование и загрузка SVG. Исходники SVG проверены XML-парсером, production-сборка выполнена успешно. Формы не менялись.
