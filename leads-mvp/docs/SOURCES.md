# Источники и границы сбора

Проверка документации выполнена **7 ноября 2026 года**. Это проверка конкретных официальных страниц, а не гарантия неизменности условий. MVP не обходит вход, CAPTCHA, блокировки и платные ограничения; не отправляет сообщения и не запускает сбор по расписанию.

| Источник | Реализация MVP | Основание и альтернатива |
|---|---|---|
| OpenStreetMap / Overpass | Работающий HTTP-адаптер без ключа, небольшой запрос по ограниченному bbox и категории | Публичная API для чтения, данные ODbL. Качество и покрытие зависят от участников OSM. Отсутствующий тег `website` **не** доказывает отсутствие сайта. |
| 2GIS | Записывает `unavailable / api_key_and_storage_permission_required`, HTTP не выполняется | Places API требует ключ/demo/subscription; поля контактов `items.contact_groups` доступны по дополнительному согласованию и за дополнительную стоимость. В MVP нет такой интеграции. Подключение ключа само по себе её не включает; импортируйте собственный список или данные, хранение которых вам разрешено. |
| Яндекс Карты | Записывает `unavailable / license_prohibits_storage`, HTTP не выполняется | Документация Organization Search API прямо указывает, что сохранение и изменение полученных API данных запрещены. Для этой базы API непригоден по стандартным условиям; наличие ключа не устраняет ограничение. Альтернатива — собственная CRM/разрешённый импорт и ручное подтверждение со ссылкой. |
| Instagram | Записывает `unavailable / no_universal_public_business_search_api`, HTTP не выполняется | Не реализован универсальный поиск местных публичных аккаунтов. API Meta требуют отдельного сценария авторизации/разрешений; наличие публичного профиля не разрешает массовый сбор. Собственный разрешённый список ссылок можно импортировать, затем вручную проверять бизнес-контакты. |
| Поисковая выдача и публичные страницы | Ручной поиск и сохранение кратких доказательств через импорт/CLI | Автоматического скрейпера поисковиков нет. Оператор проверяет название + город + телефон, ссылки из профиля и совпадение контактов сайта. Полные страницы не сохраняются. |

## Официальные документы, проверенные при реализации

* Overpass API: <https://wiki.openstreetmap.org/wiki/Overpass_API> — HTTP 200.
* Ресурсы и ограничения публичного Overpass: <https://dev.overpass-api.de/overpass-doc/en/preface/commons.html> — HTTP 200. Ориентир документации: не более примерно 10 000 запросов и 1 ГБ в сутки на пользователя; фактическая доступность зависит от текущей нагрузки, ответ 429 означает ограничение.
* Лицензия и атрибуция OpenStreetMap: <https://www.openstreetmap.org/copyright> — HTTP 200.
* 2GIS Places API: <https://docs.2gis.com/en/api/search/places/overview> — HTTP 200; ключи, подписки и платные поля контактов. Справочник: <https://docs.2gis.com/en/api/search/places/reference/3.0/items> — HTTP 200.
* Яндекс Organization Search API: <https://yandex.com/dev/commercial/doc/en/concepts/geosearch> — HTTP 200. Цитата: “saving or modifying data received from this API is prohibited”.
* Meta Instagram Platform: <https://developers.facebook.com/docs/instagram-platform/> — HTTP 200, перенаправление на <https://developers.facebook.com/documentation/instagram-platform>. Полученная страница содержала преимущественно динамическую оболочку; доступность конкретных методов поиска и права на такой сценарий не подтверждены. Поэтому сбор не включён.

## Настройка и ограничения Overpass

Переменные окружения:

```dotenv
FLARE_OVERPASS_URL=https://overpass-api.de/api/interpreter
FLARE_REQUEST_INTERVAL=3
FLARE_HTTP_TIMEOUT=30
```

Конфигурация читается из окружения процесса. Если используется `.env`, предварительно загрузите её в оболочку способом, указанным в README.

Поддерживаемые города: `Павлодар`, `Экибастуз` (также `pavlodar`, `ekibastuz`). Это ограничивающие прямоугольники, а не проверенные административные границы: адрес и принадлежность бизнесу требуют ручного подтверждения. Явно указанные в OSM другие города пропускаются.

Категории: `кафе`, `ресторан`, `парикмахерская`, `салон красоты`, `стоматология`, `автосервис`, `отель`, `магазин` (OSM `convenience`), `фитнес`. Поддерживаются соответствующие английские OSM значения из `flare/sources.py`. Произвольные строки не подставляются в запрос. `--limit` от 1 до 100; сервер получает ограничение выдачи, таймаут 20 секунд и лимит памяти. Клиент принимает максимум 2 МБ, использует HTTPS, таймаут до 60 секунд, интервал минимум 1 секунду и максимум одну повторную попытку. `Retry-After` учитывается; ожидание более 30 секунд превращается в диагностируемую ошибку для следующего ручного запуска. Отказ доступа не повторяется и не обходится.

Стабильный идентификатор OSM имеет вид `node/123`, `way/123`, `relation/123`. Телефоны берутся только из публичных `contact:phone`/`phone`, email — из `contact:email`/`email`. Тег телефона не подтверждает личность владельца и не даёт оснований для WhatsApp. Контакты поступают как непроверенные. `contact:website`/`website` — только кандидат: официальность и действующий статус не устанавливаются автоматически.

Каждый источник имеет независимую запись `collection_attempts`: время начала/окончания, город, категория, статус, число принятых записей, фиксированный код ошибки. Исключение отдельного источника или некорректная строка не прерывает остальные. Журнал не содержит ключей, полных страниц, тел ответов или телефонных номеров.

## Атрибуция и экспорт OSM

Данные OSM: **© OpenStreetMap contributors**, <https://www.openstreetmap.org/copyright>, лицензия **ODbL**. Ссылка и краткая атрибуция сохраняются вместе с происхождением наблюдений. При передаче выгрузок OSM прикладывайте этот файл или аналогичное уведомление; требования к производной базе определяются ODbL. Не удаляйте ссылки на источники из выгрузки.

## Ручная проверка официального сайта

1. Выполните поиск по названию, городу и опубликованному телефону; проверьте ссылки в карточке/бизнес-профиле.
2. Сопоставьте телефон/адрес/название сайта с бизнесом; откройте сайт и проверьте, действует ли он.
3. Сохраните краткую цитату/обоснование, ссылки, дату и уверенность. Каталог и Instagram сами по себе не считаются официальным сайтом.
4. Подтверждённый действующий официальный сайт исключает бизнес. Спорная принадлежность, недоступность сайта или неполная проверка оставляют запись на ручной проверке. «Не найден при проверке» — ограниченный результат конкретной проверки, а не доказанное отсутствие сайта.

Для недоступного источника используйте импорт CSV/XLSX по README. Импорт не делает неподтверждённые факты подтверждёнными и не отменяет запрет контакта.
