# Проверка MVP

Проверено в рабочем окружении 7 ноября 2026 года, Python 3.12.14. Код рассчитан на Python 3.11+.

## Автоматические проверки

```bash
python -m pytest -q
python -m pip check
```

Полный набор: **60 тестов**, все прошли. Проверены:

- Идемпотентность импорта и сбора, обновление названия при устойчивом ID, разделение филиалов с общим телефоном, отказ при конфликте идентификаторов.
- Устойчивое исключение по официальному сайту, запрет контакта, сохранение обработки из CRM и истории даже при ручном возврате стадии в «новый».
- Различение актуального публичного спроса, ручного интереса и гипотезы пользы; старые сигналы и проверки не допускают запись к первому звонку.
- Валидация источников подтверждения контакта и личности ответственного, удаление карточки с хешированным подавлением повторного импорта.
- CSV/XLSX, изоляция ошибочных строк, отчёты без исходных контактов, защита от табличных формул.
- Независимые попытки источников, HTTP-ограничения, robots.txt, запрет приватных адресов и переходов на другой домен при проверке сайта.
- Два сквозных сценария CLI в subprocess: импорт → готовая очередь → XLSX → запрет → повторный импорт; ошибочные строки и недоступные источники с кодами завершения.

Все компании, телефоны, HTML и ответы API внутри `tests/` — **синтетические**; они не попадают в рабочую базу. Сетевые ответы там подменены. Установка через `pip install -e '.[test]'` выполнена; `pip check` не нашёл конфликтов зависимостей.

## Реальный сбор отдельно от тестов

Выполнена команда:

```bash
flare --db data/real-smoke.sqlite3 collect \
  --city Павлодар --category кафе --sources osm,2gis,yandex,instagram --limit 5
```

Результат живого запроса Overpass 08:44 UTC: **5 реальных объектов**, **0 телефонных тегов**, **1 кандидат сайта**. Все пять требуют проверки; **готовых к звонку — 0**. Подтверждённые владельцы/ответственные и спрос не установлены. Синтетические компании не добавлялись.

2GIS, Яндекс и Instagram не запрашивались: реализованные диагностические адаптеры сохранили причины недоступности и продолжили запуск. Они перечислены в [SOURCES.md](SOURCES.md).

Повторный живой запрос OSM завершился `network_unavailable`: ошибка сохранена в `collection_attempts`, прежние пять записей остались. Поэтому успешный повторный сетевой сбор не заявляется. Для отдельной проверки идемпотентности дважды обработан ранее полученный **реальный сохранённый ответ** OSM: число компаний осталось 5. Последние две успешные попытки в этой проверочной базе — локальное воспроизведение ответа, а не новые сетевые запросы.

В этой среде доступны локальные артефакты (игнорируются `.gitignore`, не являются seed-данными проекта):

- `data/real-smoke.sqlite3` — пять записей и попытки сбора/воспроизведения;
- `exports/real-smoke.csv`, `exports/real-smoke.xlsx` — пять карточек с источниками и признаками неопределённости;
- `exports/real-ready.xlsx` — пустая готовая очередь с заголовками.

Проверены команды `init`, импорт пустого шаблона, `show`, экспорт CSV/XLSX и фильтрация готовой очереди. Реальная официальность сайта не подтверждалась: HTTP-сопоставление сайта проверено автоматическими тестами, решение об официальности остаётся ручным. Публичная доступность Overpass может меняться; воспроизводимый автономный путь — импорт своего разрешённого CSV/XLSX по README. Для автономной проверки сценария импорта с синтетическими данными выполните `python -m pytest tests/test_cli.py -q`: он сам создаёт временные файлы и отдельные базы, не требует внешних файлов или ключей.
